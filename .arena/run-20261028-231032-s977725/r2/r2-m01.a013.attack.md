ATTACK 1 [MAJOR] Overstates when the camera preview stops
Where: “its code stops the tracks on slide changes, page hiding, exit, and unload.”
Problem: The exit trigger does not stop the camera when the user clicks “CLOSE THE APP — FREE, ALWAYS”; it only opens the dismissible deletion dialog. If the user dismisses the ₹2,000 joke or chooses “KEEP REFLECTING,” the preview remains live. Only the separate “CLOSE FOR FREE” action calls stopCamera(). The stated behavior is therefore false for the first exit action, and the review's privacy assurance should distinguish opening the exit dialog from actually closing.
